# New Look by Suruchi

**Official Website – Unisex Salon, Academy & Studio**

A modern, responsive website for New Look by Suruchi, a beauty salon and professional makeup studio based in Dehri-on-Sone, Bihar, India.

## About

The website helps customers explore salon services, discover professional makeup and bridal portfolios, and learn about cosmetology training programs.

## Features

- Responsive and mobile-friendly design
- Salon, Studio and Academy sections
- Makeup and hairstyle portfolio
- Appointment and contact information
- WhatsApp inquiry integration
- Business location and directions
- Optimized performance and accessibility

## Tech Stack

- HTML5
- CSS3
- JavaScript
